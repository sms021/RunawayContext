### Why the rename?

The name "SuperContext" conflicts with several existing projects. To avoid confusion and improve discoverability, the project was renamed to **RunawayContext** (by [Runaway Ideas](https://github.com/sms021)).

### What changed?

- Project renamed from SuperContext to RunawayContext
- Session capture now covers all three lifecycle events (compaction, clear, exit) — not just exit
- All files, templates, and instructions updated to reflect the new name
- Everything else is the same system you know
